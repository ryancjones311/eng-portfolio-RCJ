# Ryan Jones — Mechanical Engineering Portfolio

Plain HTML/CSS/JS site (no build step), served by GitHub Pages.

## Structure
- `index.html` — home page with project cards
- `projects/*.html` — one detail page per project
- `assets/images`, `assets/video` — figures and videos
- `css/style.css`, `js/site.js` — styles and image lightbox

## Common edits
- Resume: save your PDF as `assets/resume/Ryan-Jones-Resume.pdf`
- LEGO robot video: see the commented `VIDEO` block in `projects/lego-line-following-robot.html`
- Email button: see "TO ADD EMAIL" in `index.html`

## Deploy
Repo Settings → Pages → Deploy from branch → `main` / root.
